## ケースは現実ではなく想定を符号化している

`eval/cases.ts` の 6 ケースは、ローンチ時に想像した範囲をカバーしています。1 日の旅行、複数日の旅程、食事の提案、制約の確認です。本番のトラフィックは違って見えます。

- **複数都市のクエリ**: 「Luminara に 2 日滞在してから海岸へ向かいます。両方を計画してもらえますか」
- **アクセシビリティの要件**: 「祖母が車椅子を使います。どの観光地がアクセシブルですか」
- **予算の制約**: 「食事込みで 1 日 200 ドル以内の旅行を計画してください」
- **時間に関するエッジケース**: 「金曜の午後 11 時に到着します。まだ開いているのは何ですか」
- **否定の制約**: 「旅行を計画してください。ただし事前予約が必要なものはすべて除いてください」

ケースはこれらを 1 つもカバーしていません。それでも Online Eval はそうしたセッションを採点し、低いスコアが積み上がっています。

## 低スコアのセッションはノイズではなくシグナルである

それぞれが具体的なことを教えてくれます。ケースがカバーしていない質問をユーザーがした、応答が不十分だった (ジャッジがその理由を述べます)、あるいはトラジェクトリが誤っていた (ツールが誤って呼ばれたか、まったく呼ばれなかった) のいずれかです。それはスイートが動かしていない *実際のユーザーニーズ* であり、グラウンドトゥルースがそうあるべきものです。

:::alert{type="success" header="持ち帰るべき 1 つの考え: 固定のしきい値ではなく、分布の下端をトリアージする"}
健全なシステムではスコアは高いところに集まる (約 0.8 〜 1.0) ため、`< 0.8` のしきい値はある日は何も見つけず、別の日はすべてを拾います。昇順に並べて、絶対的なスコアがどうであれ最悪のセッションを取ってください。評価 *エラー* を含むセッションにも注意が必要です。
:::

## ループ: 本番が開発に情報を与え、開発が本番を改善する

![グラウンドトゥルースのループ: 本番セッションが採点され、最低のスコアとエラーが抽出され、それらが Case オブジェクトになり、それに対してエージェントを修正し、そのデプロイはそれらのケースによって恒久的に守られる。](/static/images/diagrams/module4-ground-truth-loop.png)

本番データがテストスイートを駆動し、スイートがエージェントの改善を駆動し、それが本番に戻って再び採点されます。ループは止まりません。ただ締まっていくだけです。

## 必要なもの

- モジュール 2 の評価結果ロググループ (`agentcore-eval-and-obs.yaml` スタックが作成)
- `eval/cases.ts` の `Case` インターフェース
- 抽出と変換を自動化するコーディングエージェント

## ここでのコーディングエージェントは Claude Code です

Code Editor には **Claude Code** が同梱され、ワークショップのアカウントで Amazon Bedrock に配線済みなので、ログインも API キーの設定も不要です。ターミナルを開き (**Terminal → New Terminal**)、`claude` を実行するか、サイドパネルを使ってください。ステップが「ご自身のコーディングエージェント」または「AI サイドバー」と言っている箇所は、すべて Claude Code のことです。同じプロンプトは Kiro、Cursor、あるいは職場でお使いのものでも動きます。

:::alert{type="info" header="仕組み: 1 つのナレッジベース、2 つのネイティブ形式"}
このモジュールの専門知識は **Powers** (`kiro-powers/*/POWER.md`) として提供されます。Kiro のネイティブ形式であり、どのエージェントもパス指定で読めるプレーンな markdown でもあります。Claude Code 向けには **skills** としてネイティブに登録もされています。`travel-agent/.claude/skills/` が Power ごとに、正式な POWER.md を指す薄い skill を保持しているので、`travel-agent/` から実行すると Claude Code はこれらの機能を自動的に *発見* します。

Power をパスで参照する (ステップがそうしており、どのエージェントでも動きます) か、タスクを説明して Claude Code に対応する skill を引き込ませてください。どちらでも内容は同じで、真実の情報源は 1 つです。
:::
